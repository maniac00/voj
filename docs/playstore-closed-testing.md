# Play Store 비공개 테스트 재진행 가이드

2026-10-04 작성. 첫 14일 비공개 테스트 후 Google이 **추가 테스트(2주)** 를 요구한 상황 대응용.
제출 절차 전반은 `docs/playstore-submission.md` 참조.

## 왜 2주를 더 요구받았나

Google 안내문의 "앱에 추가 테스트가 필요한 경우" 항목이 그대로 사유다. 실제 원인은 다음 셋 중 하나:

| 사유 | 확인 위치 |
|------|-----------|
| 옵트인 테스터가 12명 미만 | 테스트 및 출시 → 테스트 → 비공개 테스트 → **테스터** 탭 (옵트인 수 표시) |
| 14일 "연속" 유지가 끊김 (중간에 1명이라도 옵트아웃 → 카운터 리셋) | 같은 화면의 옵트인 추이 |
| 테스터가 옵트인만 하고 **실제 설치·사용을 하지 않음** (가장 흔함) | 통계 → 설치 수 / 테스트 의견 페이지가 비어 있는지 |

> ⚠️ 핵심: 요건은 "이메일 목록에 12명 등록"이 아니라 **12명이 옵트인 링크로 참여해 앱을 설치하고 실제로 사용한 상태가 14일 연속 유지**되는 것이다.
> 이메일만 등록해 두고 테스터가 링크를 누르지 않으면 옵트인 0명으로 집계된다.

## 즉시 해야 할 일 (오늘)

1. **옵트인 실제 인원 확인** — 비공개 테스트 → 테스터 탭. 12명 미만이면 그게 탈락 사유 확정.
2. **설치 수 확인** — 통계에서 활성 설치 수가 옵트인 수와 비슷한지. 차이가 크면 "옵트인만 하고 미설치" 상태.
3. **테스트 의견 확인** — 모니터링 및 개선 → 평점 및 리뷰 → **테스트 의견**. 비어 있으면 신청서 2·3단계를 채울 근거가 없으므로 반드시 수집해야 한다.
4. **테스터 여유 확보** — 옵트인 **16~20명** 목표로 재모집. 12명 턱걸이는 1명 이탈로 14일이 리셋되므로 금물.
5. **Google 그룹으로 전환 권장** — 이메일 목록 방식은 추가/제거 시마다 릴리스 저장이 필요하다. Google 그룹(예: `voj-testers@googlegroups.com`) 하나를 테스터로 지정하면 그룹 멤버만 관리하면 된다.

## 테스터에게 보낼 안내문 (카톡·문자용)

```
[주안의 소리 앱 테스트 참여 안내]

안녕하세요. 시각장애인을 위한 오디오북 앱 '주안의 소리'를 구글 플레이스토어에
정식 출시하기 위해, 2주간 테스트에 참여해 주실 분들을 모집합니다.

■ 참여 방법 (3분 소요, 안드로이드 폰만 가능)
1) 아래 링크를 눌러 '테스터가 되기' 버튼을 눌러 주세요.
   → (Play Console 비공개 테스트 참여 링크)
2) 이어서 나오는 '구글 플레이에서 다운로드' 링크로 앱을 설치해 주세요.
3) 앱을 열어 한 번이라도 사용해 주세요. (설치만 하면 집계되지 않습니다)

■ 꼭 지켜주셔야 하는 것
• 테스트 참여를 **2주(10월 20일까지) 동안 해제하지 말아 주세요.**
  중간에 한 분이라도 빠지면 구글의 2주 계산이 처음부터 다시 시작됩니다.
• 앱을 삭제하셔도 테스트 참여 상태는 유지되지만, 가능하면 설치해 두세요.

■ 의견 보내는 방법 (중요)
구글에 제출할 자료로 쓰이므로 짧게라도 한 번씩 부탁드립니다.
• 플레이스토어 앱 → 주안의 소리 → 맨 아래 '앱 의견 보내기' 또는
• 저에게 카톡으로 직접 보내주셔도 됩니다.

■ 이런 점을 봐주시면 좋습니다
• 로그인이 잘 되는지 / 책 목록과 검색이 잘 보이는지
• 재생·일시정지, 10초 되감기, 다음 트랙 이동이 잘 되는지
• 앱을 껐다 다시 열었을 때 듣던 위치부터 이어지는지
• 화면을 끈 상태에서도 소리가 계속 나는지
• 글자가 읽기 편한지, 버튼이 누르기 쉬운지
• (가능하시면) 안드로이드 TalkBack을 켜고 음성 안내만으로 조작이 되는지

감사합니다.
```

### 2단계 — 앱/게임 정보 (앱이 사용자에게 제공하는 가치)

```
주안의 소리(Voice of Juan)는 시각장애인과 저시력 사용자가 책을 '들어서' 읽을 수 있도록
만든 무료 오디오북 스트리밍 앱입니다.

[해결하려는 문제]
시각장애인은 인쇄물에 직접 접근할 수 없어, 읽고 싶은 책이 음성도서로 제작되어 있지
않으면 사실상 읽을 방법이 없습니다. 특히 설교집·신앙 서적처럼 수요가 한정된 분야는
음성도서 제작이 거의 이루어지지 않습니다. 그동안은 낭독 봉사자가 녹음한 파일이나 CD를
개별적으로 전달받아야 했기 때문에, 원하는 시점에 원하는 책을 듣는 것이 불가능했습니다.

[앱이 제공하는 가치]
1) 접근 가능한 콘텐츠 제공 — 낭독자가 직접 녹음한 도서를 앱에서 바로 스트리밍으로
   들을 수 있습니다. 별도의 파일 전달이나 기기 연결이 필요하지 않습니다.
2) 화면을 보지 않고도 완결되는 사용 경험 — TalkBack 화면 낭독기를 지원하며, 모든
   버튼에 음성 안내 레이블을 부여했습니다. 큰 터치 영역, 높은 명도 대비, 단순하고
   일관된 화면 구조로 저시력 사용자도 스스로 탐색할 수 있습니다.
3) 청취 경험을 이어주는 기능 — 듣던 위치를 자동 저장하는 이어듣기, 재생 속도 조절,
   10초 되감기/빨리감기, 트랙 이동, 백그라운드·잠금화면 재생 제어를 제공합니다.
   시각장애인에게 '마지막에 듣던 곳을 다시 찾는 일'은 특히 어려운 작업이므로
   이어듣기는 핵심 가치에 해당합니다.
4) 비용 장벽 없음 — 모든 콘텐츠가 무료이며 광고와 인앱 결제가 전혀 없습니다.
   주안장로교회가 시각장애인의 도서 접근권 향상을 위해 비영리로 운영합니다.
5) 가입 없이 체험 가능 — 로그인 없이 '둘러보기(게스트 모드)'로 도서 목록을 탐색하고
   샘플 청취를 할 수 있어, 계정을 만들기 어려운 사용자도 앱의 가치를 먼저 확인할 수 있습니다.

[요약]
이 앱은 기존에 접근할 수 없었던 도서를 시각장애인이 직접, 무료로, 도움 없이 들을 수
있게 만드는 것을 목적으로 합니다. 접근성은 부가 기능이 아니라 이 앱의 존재 이유입니다.
```
