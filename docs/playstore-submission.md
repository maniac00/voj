## Play Console 제출 절차

1. **개발자 계정**: https://play.google.com/console — 계정 없으면 등록 (일회 $25)
2. **앱 만들기**: 앱 이름 위 참조, 기본 언어 `한국어(대한민국)`, 유형 `앱`, `무료`
3. **초기 설정 설문** (대시보드 → 앱 설정):
   - 앱 액세스: "일부 기능이 제한됨" 선택 → 안내문에 기재:
     "로그인 없이 둘러보기(게스트 모드)로 도서 탐색·체험 청취 가능. 전체 기능은 아무 Google 계정으로나 즉시 가입 가능 (승인 절차 없음)."
   - 광고: 광고 없음
   - 콘텐츠 등급: 설문 작성 → 카테고리 "참고자료, 뉴스 또는 교육" → 폭력·성적 콘텐츠·도박·약물 모두 "아니요" → 전체이용가 예상
   - 타겟층: 만 13세 이상 (어린이 대상 아님)
   - 뉴스 앱: 아니요
   - 데이터 보안: 아래 섹션 참조
   - 정부 앱: 아니요 / 금융 기능: 없음 / 건강 앱: 아니요
4. **스토어 등록정보**: 위 텍스트 + `appstore/playstore/` 그래픽 업로드, 개인정보처리방침 URL 입력
5. **프로덕션 릴리스**: 프로덕션 트랙 → 새 릴리스 → `app-release.aab` 업로드
   - **Play 앱 서명 등록 시 반드시 "기존 키 사용"을 선택**하고 `mobile/android/voj-release.keystore`의 키를 내보내 업로드할 것.
     (Google 생성 키를 쓰면 R2로 배포한 APK와 서명이 달라져 기존 사용자가 Play 버전으로 업데이트 불가)
   - 키 내보내기: Play Console이 안내하는 `pepk` 도구 사용, keystore 비밀번호는 `mobile/android/key.properties` 참조
6. **국가/지역**: 대한민국 (필요 시 전체 국가)
7. **검토 제출** — 심사는 보통 1~7일

## 심사 대비 참고

- 게스트 모드(로그인 없이 둘러보기)가 있어 심사자가 계정 없이도 핵심 기능 확인 가능
- 심사용 로그인이 필요하면 "앱 액세스"에 아무 Google 계정이나 즉시 가입됨을 명시 (별도 데모 계정 불필요)
- 종교 콘텐츠(설교집)는 등급 설문의 제한 항목에 해당하지 않음
